# SUBIL OS

منصة التشغيل الرقمية المتكاملة لمؤسسة سبيل المتحدة للتجارة.

## الهدف
بناء منصة واحدة تدير دورة النشاط كاملة: التجارة الإلكترونية، العملاء، الفنيين والخدمة الميدانية، المالية، المخزون، التسويق، التحليلات، والتكاملات والذكاء الاصطناعي.

## التطبيقات
- `apps/web` — موقع ومتجر العميل
- `apps/admin` — لوحة الإدارة
- `apps/technician` — بوابة/تطبيق الفني
- `apps/mobile` — تطبيق العميل
- `apps/api` — واجهة النظام والخدمات الخلفية

## الوحدات الأساسية
- Identity & Access
- Commerce
- CRM
- Field Service
- Finance
- Inventory & Procurement
- Marketing & Social Hub
- Notifications
- Analytics
- AI Agents
- Integrations

## سياسة الفروع
- `main`: الإنتاج المستقر فقط
- `develop`: التكامل والتطوير
- `feature/*`: كل ميزة مستقلة

## قاعدة الأمان
لا يتم نشر كود تجريبي مباشرة على `subil.store`. أي تطوير يمر ببيئة تطوير/اختبار ثم مراجعة قبل الإنتاج.
