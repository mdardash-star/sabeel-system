# SUBIL OS

منصة التشغيل الرقمية المتكاملة لمؤسسة سبيل المتحدة للتجارة.

## الهدف
بناء منصة واحدة تدير دورة النشاط كاملة: التجارة الإلكترونية، العملاء، الفنيين والخدمة الميدانية، المالية، المخزون، التسويق، التحليلات، والتكاملات والذكاء الاصطناعي.

## التطبيقات
- `apps/web` — موقع ومتجر العميل
- `apps/admin` — لوحة الإدارة
- `apps/technician` — بوابة/تطبيق الفني
- `apps/mobile` — تطبيق العميل
- `apps/api` — واجهة النظام والخدمات الخلفية

## الوحدات الأساسية
- Identity & Access
- Commerce
- CRM
- Field Service
- Finance
- Inventory & Procurement
- Marketing & Social Hub
- Notifications
- Analytics
- AI Agents
- Integrations

## سياسة الفروع
- `main`: الإنتاج المستقر فقط
- `develop`: التكامل والتطوير
- `feature/*`: كل ميزة مستقلة

## قاعدة الأمان
لا يتم نشر كود تجريبي مباشرة على `subil.store`. أي تطوير يمر ببيئة تطوير/اختبار ثم مراجعة قبل الإنتاج.

## الحالة
Core API foundation + Admin Web preview.

## معاينة لوحة الإدارة
```bash
npm install
npm run dev:admin
```

ثم افتح `http://localhost:3000`. تستخدم واجهة المعاينة بيانات تجريبية فقط ولا تتصل بالمتجر المباشر.

## معاينة بوابة الفني
```bash
npm run dev:technician
```

ثم افتح `http://localhost:3002`. تدعم البوابة دخول الفني برقم الجوال وOTP، مهام اليوم، انتقالات العمل، إثبات الإنجاز، المحفظة والتثبيت كتطبيق PWA.

## معاينة تطبيق العميل
```bash
npm run dev:mobile
```

ثم افتح `http://localhost:3003`. يتيح التطبيق للعميل الدخول برقم الجوال، متابعة الطلب والخدمة، إدارة الأجهزة ومواعيد الصيانة، وتقييم الخدمة المكتملة.
